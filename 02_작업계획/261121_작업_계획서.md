# 5일차 작업 계획서

- 날짜:2026-11-21

## 1. 목표

- 본사와 지사의 경로를 RIPv2로 바꿔 지사에 네트워크가 늘어도 본사와 저절로 연결될 수 있게 한다.
- 동적 라우팅이 잘못된 경로를 받아들이지 않게 한다.

## 2. 작업 대상

| 대상 | 무엇을 |
|------|--------|
| BR-R1, HQ-R1 | 주 정적 경로 삭제 / RIPv2 / passive-interface / 인증 |
| HQ-R1              | 예비 경로를 192.168.100.0 /24 |
| BR-R1 | 창고 네트워크 (루프백 1 / 192.168.20.32 /27) |

## 3. 작업 내용

1. 주 회선의 정적 라우팅 경로를 지운다. (예비 경로는 남긴다.)
2. 두 라우터에 RIPv2를 켠다.
3. 예비 회선을 passive 모드로 둔다.
4. 지사에 창고(물류센터 네트워크)를 만들어 동적 라우팅 되는지 확인한다.
5. 장애 실습 하고 예비 경로를 /24로 바꾼다.
6. 사무실 쪽 포트를 passive 모드로 두고 RIP이 켜진 포트에 모두 인증을 설정한다.

## 4. 확인 방법

| 확인할 것                     | 방법                                                        | 기대하는 결과                     |
| ------------------------- | --------------------------------------------------------- | --------------------------- |
| RIP 경로가 들어왔다              | `show ip route rip`                                       | R 192.168.20.0/27 [120/1]   |
| 예비 회선은 RIP을 타지 않는다        | `show ip route rip`                                       | R 줄이 Gi0/1 하나               |
| 새 네트워크가 퍼진다               | 창고를 만들고 본사에서 `show ip route rip`                          | R 192.168.20.32/27          |
| 장애 때 넘어간다                 | 주 회선 shutdown 중 `ping -t`                                 | 몇 개 빠진 뒤 Reply, 창고까지        |
| passive 뒤에도 지사 경로가 그대로 있다 | passive 뒤 `show ip route rip`                             | R 192.168.20.0/27 이 그대로 있다  |
| 가짜 장비를 찾았다                | `show ip protocols`, `show arp`, `show mac address-table` | 192.168.10.20, 그 MAC, Fa0/3 |

## 5. 되돌리는 방법

- 포트를 격리했다면 `no shutdown` 으로 되돌린다. passive는 `no passive-interface` 로 푼다
- RIP이 꼬이면 `no router rip` 으로 지우고, `configs/` 의 4일차 설정에서 정적 경로를 다시 입력한다
