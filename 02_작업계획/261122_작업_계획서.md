# 6일차 작업 계획서

- 날짜:2026-11-22

## 1. 목표

- RIP의 회선 속도를 모르고 장애를 늦게 알아채는 문제를 OSPF로 풀수 있는지 실험한다.
- 실험은 OSPF 브랜치에서 진행하고, 비교한 후 병합한다.

## 2. 작업 대상

| 대상 | 무엇을 |
|------|--------|
| BR-R1, HQ-R1 | RIP와 예비 정적 경로 삭제 / 루프백 0 / OSPF / passive / MD5 인증 |
| BR-R1 | 창고 네트워크 (루프백 1 / 192.168.20.32 /27) |

## 3. 작업 내용

1. OSPF 브랜치를 만든다.
2. RIP와 예비 정적 경로를 지운다.
3. 루프백 0와 router-id 를 정한다.
4. area 0 하나로 OSPF 활성화 한다.
5. 이웃, 경로, 비용을 확인하고 장애 실험을 한다.
6. passive-interface default 로 사무실 쪽을 닫는다.
7. 이웃 구간 네 곳에 MD5 인증을 건다.
(먼저 HQ-R1에만 걸어서 이웃이 끊기는 것을 확인하고 BR-R1에 설정하여 이웃이 연결되는 것을 확인한다.)

## 4. 확인 방법

| 확인할 것             | 방법                                                      | 기대하는 결과                                                               |
| ----------------- | ------------------------------------------------------- | --------------------------------------------------------------------- |
| 이웃이 맺어졌다          | `show ip ospf neighbor`                                 | 192.168.255.2 두 줄, FULL                                               |
| 주 회선을 쓴다          | `show ip route ospf`                                    | `O 192.168.20.0/27 [110/2]` via Gi0/1                                 |
| 예비 회선으로 넘어간다      | 주 회선 shutdown                                           | `[110/65]` via Se0/3/0                                                |
| 창고가 /27로 보인다      | `show ip route ospf`                                    | `O 192.168.20.32/27`                                                  |
| 사무실 쪽은 이웃을 맺지 않는다 | `show ip protocols`                                     | Passive Interface(s)에 사무실 쪽 포트                                        |
| 한쪽만 걸면 이웃이 끊긴다    | HQ-R1에만 건 뒤 `show ip ospf neighbor`                     | 약 40초 뒤 이웃이 없다                                                        |
| 인증이 맞다            | `show ip ospf interface gi0/1`, `show ip ospf neighbor` | `Message digest authentication enabled`, `Youngest key id is 1`, FULL |

## 5. 되돌리는 방법

- 모든 변경은 ospf 브랜치에 있다. 실험이 실패하면 `git switch main` 으로 RIP 판으로 돌아간다
- 인증 뒤 이웃이 돌아오지 않으면 두 라우터의 포트에서 `no ip ospf authentication` 을 입력한다
- 장비에서 꼬이면 `no router ospf 1` 로 지우고 main의 `configs/` 설정을 붙여 넣는다
